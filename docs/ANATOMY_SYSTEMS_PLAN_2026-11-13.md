# Anatomy visuals and practice plan

1. Fix the mobile homepage search and add one decorative atlas background. Verify readable input, text contrast, query submission and layout at 320 px with enlarged text, normal mobile and desktop widths.
2. Build a body-systems explorer linked from Home, Start Here and Anatomy. Give all 11 systems a first model with an objective, a labelled diagram, a specific observation prompt, explained questions, a written explanation and a linked existing lesson. Use one interaction pattern and the shared checkpoint and progress engine.
3. Review the existing Phase 2 draft (#91) separately. Check that a beginner, a student searching for a concept and a student seeking practice can each reach the intended next action. Use the existing tissue, membrane and enzyme pathways when testing with students.
4. Deepen anatomy one region or relationship at a time. Prioritise cardiac and respiratory routes, then neuroanatomy and musculoskeletal relationships, then abdominal and pelvic pathways. Add spatial comparisons, additional views and unfamiliar application questions where they improve understanding. Check each model against the existing lesson and record the source and illustration scope.
5. Use the existing first-visit testing protocol and specialist review records. Check whether students can choose a model, explain an unfamiliar example and return to their practice. Record scientific review against the actual content version.

The explorer starts with one model per system. The regional anatomy course supplies the detailed lesson order. The background artwork is decorative. The study diagrams are original simplified schematics with their own text equivalents and linked anatomy references.

For a model to be ready for review, all diagram controls must work with a keyboard, labels must remain readable at narrow widths, static text must be available with JavaScript disabled and existing browser progress must still load. Published source and asset provenance remains in the existing curation process.

## First implementation and artwork

The initial implementation adds 11 models, 22 objective questions with option-specific feedback and 11 written recall prompts. The cardiovascular model traces both circuits and the reproductive model compares two separate pathways. The other models introduce one anatomical relationship each. Every model links to an existing deeper lesson and to its OpenStax chapter.

The homepage atlas background is original decorative artwork generated with the built-in ImageGen tool. The prompt called for a wide ivory-paper anatomical atlas engraving with muted teal and graphite linework, a rib cage and shoulder girdle overlapping a small branching capillary study on the right, and quiet space for website text on the left. The site uses 1440 px and 720 px WebP variants.
