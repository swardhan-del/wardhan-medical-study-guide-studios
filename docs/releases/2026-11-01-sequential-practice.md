# One question at a time — 1 November 2026

Lesson Knowledge Checks and application sets now show one question at a time. Students select an answer, check it, read the explanation and choose Next question. Correct and incorrect feedback is explicit in text and styling; answers do not advance automatically. The existing explanations for the correct answer and every distractor remain available.

A checked-question progress bar and results summary distinguish correct, incorrect and unchecked questions. Students can revisit mistakes, review the set or start a fresh round. Retries preserve first-attempt history and the existing spaced-review rules. My Study uses the same sequence with a fresh answer required before advancing. All-question revision remains available, as do existing question/activity links and saved checked answers.

This release changes presentation and navigation. Question text, options, option order, keys, question/progress identifiers, routes and storage schema are unchanged. Existing renal quizzes retain their sequence and gain explicit incorrect-answer wording. Specimen, diagram and clinical-table activities retain their context; open-ended work receives no invented automatic grade.

No new medical lesson, scientific explanation, source or asset is introduced. This release does not establish independent medical, editorial, human accessibility or public-rights approval. Held lesson, diagram and membership drafts remain outside its scope.

Validation uses the existing content, unit, lint, typecheck, production build, privacy and browser gates. Added browser coverage exercises positive/negative feedback, deliberate progression, results, retries, saved history, direct links, My Study, blocked storage, keyboard focus and a 320-pixel mobile viewport. Existing exhaustive question/key checks use the all-question revision view. Exact-head CI and deployment evidence are recorded separately in the pull request.
