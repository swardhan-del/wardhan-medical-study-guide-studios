# Answer-first recall across the lesson library — 2 November 2026

Students could browse and reveal recap cards, but could not draft an answer, decide what needed more practice, or repeat a weaker subset in the same flow. The shared recall component now offers an optional practice round: answer in writing or aloud, reveal the existing model, self-check, and repeat weaker cards. The original browse mode remains available.

## Coverage and learning boundary

All 241 native library lessons and eight renal lessons receive the same interaction. It uses 1,248 existing explanation/recall prompts and model responses, with at least four prompts per lesson. This is a count of reused learning material, **not 1,248 newly authored or medically validated examination questions**. Foundation lessons now share this recap interaction; renal cards use their existing sections and oral rubric.

No medical teaching JSON, question wording, answer position, question/progress ID, source record or frozen quality baseline changes. Existing graded quizzes still provide correct/incorrect feedback. Recall self-checks are explicitly personal judgments and do not modify quiz history, completion, spaced-review streaks or mastery claims.

## Privacy and accessibility

Typed recall responses and self-checks stay in component memory for the visit. Reload clears them. They are not sent to a server or AI grader, written to browser storage, exported, or recorded as analytics events. Existing saved oral notes are separate and retain their identities and behavior.

Answers remain hidden until requested, one prompt appears at a time, keyboard focus follows navigation, and a self-check is required to advance in practice mode. Weaker rounds clear the previous draft and hide the model again. Text labels distinguish the two self-checks, alongside contrast and focus styling. Automated accessibility checks do not replace a human accessibility review.

## Question expansion standard

The owner's request for more questions per lesson still requires content work. Reuse the existing content-quality pipeline and conversion-brief template. Begin with six varied items where scope warrants them: direct retrieval, mechanism reasoning, application and misconception discrimination. This is an editorial planning minimum, not a proven optimal quantity or permission to add filler. Larger foundation lessons may need more; a count alone does not demonstrate adequate assessment.

Each new item needs an objective, controlling source edition/section, unambiguous best answer, plausible alternatives, explanations for every option and exact-version review. Quantitative questions need assumptions and units. Visual questions need an accessible equivalent and applicable rights. Preserve existing IDs/answer positions and the legacy baseline. Do not mass-release unreviewed AI-generated question banks.

Existing drafts #29/#30 already contain assessment and curriculum work. Reconcile their actual question/content differences before authoring overlapping material. A new private five-item DNA-replication candidate set and an all-249-lesson coverage inventory are outside Git; they are drafts, not released questions or approval evidence. Qualified scientific, editorial, human accessibility, applicable rights/controller and owner release decisions remain pending for new assessment content.

## Product and discovery priorities

1. Complete one coherent, reviewed free pathway before expanding the public catalogue merely for volume.
2. Improve explained practice and interpretation tasks within that pathway, including independently cleared visual identification where appropriate.
3. Observe appropriately consented student sessions. Separate observed friction, reported preferences and unknown outcomes.
4. Use the existing measurement framework only with approved privacy/configuration. Track eligible lesson-to-quiz completion, next-lesson use, seven-day return and corrections rather than treating pageviews as demand. No provider is enabled by this change.
5. Reuse the existing topic pages, titles, canonicals, sitemap and link registry. Verify Search Console access and indexing before claiming search traction. No SEO settings, domains or DNS change here.
6. Draft distribution around useful free resources and real feedback. No outreach, posting, advertising spend, endorsement or paid-membership launch is performed.

Retrieval, revisiting content and spacing are supported by the [IES learning practice guide](https://ies.ed.gov/ncee/wwc/PracticeGuide/1); that research is not an effectiveness trial of this feature. [Google's people-first content guidance](https://developers.google.com/search/docs/fundamentals/creating-helpful-content) supports prioritising useful, reliable content; it does not guarantee rankings or traffic.
