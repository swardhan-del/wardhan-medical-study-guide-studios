# Private conversion brief template

Copy this template into the ignored conversion queue before filling in source filenames. Never store raw source paths, copied source passages or uncleared visuals in this public document.

- Queue ID and proposed student-facing title:
- Status: private planning only; no publication approval.
- Source files: exact intake-relative filenames, edition/section, byte size and SHA-256 where read successfully.
- Curation match: exact governing model record ID and approved-private manifest match, or explicit mismatch. Public-release decision is separate.
- Intended audience: learner stage, assumed knowledge, international terminology and scope limits.
- Learning objectives: assessable tasks and expected depth.
- Scope: inclusions, exclusions, uncertainties and overlap with existing published lessons.
- Visual needs: the relationship to teach, original/right-cleared approach, scientific/rights reviewer, caption/alt-text requirements and responsive preparation.
- References to verify: exact edition/section or primary reference; record actual access dates only after verification.
- Proposed questions: objective tested, stem constraints, verified best answer, plausible alternatives and an explanation for each option; model responses for open prompts.
- Relationships: valid existing prerequisite/related/compare/next IDs. Proposed queue items are not links to public routes.
- Publication blockers: unapproved edition, unclear rights, unresolved scientific questions, duplicate scope, missing explanations or unfinished accessibility/readability checks.
- Review handoff: responsible next reviewer, evidence still needed, last action and next safe step.

Only after adaptation and the necessary reviews should public-safe bibliographic metadata enter the lesson-quality register. Start with explicit pending statuses and `noindex-pending-review`. Follow CONTENT_QUALITY_PIPELINE.md; do not update the legacy baseline to bypass the gates.
